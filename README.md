# Oshi Extension: eduVULCAN / UONET+

[![Oshi Compatible](https://img.shields.io/badge/Oshi-Extension-7c3aed.svg)](https://github.com/Ogaku/Oshi)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Official register provider extension for [**eduVULCAN**](https://eduvulcan.pl) and **UONET+** in [**Oshi**](https://github.com/Ogaku/Oshi).

## Features
- Timetable, room numbers, and canceled lessons
- Partial and semester grades
- Attendances, absences, and excuses
- Messages and teacher notices

## Installation in Oshi
1. Open **Oshi**.
2. Go to **Settings > Manage Extensions** (or during initial setup).
3. Select **eduVULCAN / UONET+** or install directly via URL:
   `
   https://raw.githubusercontent.com/Ogaku/Oshi-Extension-Vulcan/main/extension.dart
   `
4. Log in with your eduVULCAN account.
